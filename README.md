## ✨ Overview

This is my personal developer portfolio, built to present my **projects, technical skills, certifications, achievements, coding profiles, resume and professional journey** through a modern and interactive interface.

The portfolio focuses on combining **clean visual design, smooth interactions, responsive layouts and strong project presentation** to create a professional experience across desktop, tablet and mobile devices.

> **The goal is simple: turn a portfolio from a static resume into an interactive representation of how I build.**

## 🎨 Design Philosophy

The portfolio is designed around a few principles:

```text
01. CLARITY
    Keep information easy to understand.

02. CONSISTENCY
    Maintain a coherent visual language.

03. INTERACTION
    Use animation to enhance, not distract.

04. RESPONSIVENESS
    Design for every screen size.

05. PERFORMANCE
    Keep the experience lightweight and fast.

06. STORYTELLING
    Let projects communicate what I can build.
```

## ⚙️ Run Locally

Clone the repository:

```bash
git clone https://github.com/Mratunjaypandey/mratunjay-portfoliolink.git
```

Move into the project directory:

```bash
cd mratunjay-portfoliolink
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open the local development URL shown in your terminal.
